# Atlas

Ein persönlicher Sprachassistent für Android (Web-App plus kleine Handy-App). Jede Person betreibt ihre eigene Kopie mit eigenen Daten und Schlüsseln.

Anleitung zum Einrichten: **[INSTALL.md](INSTALL.md)**.

Enthalten: Wetter, Nachrichten, Kalender, Erinnerungen, Listen, Notizen, Fahrzeit, WhatsApp lesen und beantworten, Spotify, Bundesliga, Hey-Atlas-Weckwort, Einrichtungsassistent und Update-Meldung.
